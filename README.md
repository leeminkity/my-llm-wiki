# my-llm-wiki — AI를 활용한 마케팅 위키

현업 마케터를 위한 글·강의를 만들기 위해, **AI를 활용한 마케팅**에 대한 자료를 모으고 정리하는 개인 위키입니다.

안드레 카파시(Andrej Karpathy)의 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 방식을 따릅니다.
사람은 자료를 고르고 질문을 던지고, AI는 요약·연결·정리를 맡습니다.

## 어떻게 돌아가나

1. **자료를 넣는다** — 기사, 보고서, 메모, 광고 캡처를 `raw/`에 넣는다.
2. **AI가 정리한다** — AI가 읽고 핵심을 먼저 보여 준 뒤, 함께 정한 대로 `wiki/`에 요약·개념·도구·사례 페이지를 쓰고 서로 연결한다.
3. **위키가 자란다** — 자료가 쌓일수록 페이지가 서로 이어지고, 전체 그림(`wiki/overview.md`)이 점점 뚜렷해진다.
4. **글·강의로 만든다** — 쌓인 지식으로 `wiki/content/`에서 글감과 강의 개요를 만든다.

## 폴더

| 폴더 | 내용 | 깃허브 공개 |
|---|---|---|
| `wiki/` | AI가 정리한 노트 (목차, 일지, 전체 그림, 자료 요약, 개념, 도구, 사례, 분석, 글감) | 공개 |
| `templates/` | 페이지 종류별 서식 | 공개 |
| `raw/` | 원본 자료 | **비공개** (주인 컴퓨터에만) |
| `CLAUDE.md` | AI가 따르는 규칙서 — 이 위키의 맥락과 작업 방식 | 공개 |

## 시작점

- [목차](wiki/index.md)
- [전체 그림](wiki/overview.md)
- [작업 일지](wiki/log.md)

옵시디언(Obsidian)으로 이 폴더를 열면 페이지 사이 연결을 그림(그래프 보기)으로 볼 수 있습니다.

## 출처 안내

`wiki/`의 내용은 여러 공개 자료를 자기 말로 요약한 것이며, 각 페이지에 출처를 밝혀 두었습니다.
원본 자료는 저작권 보호를 위해 올리지 않습니다.
